# Command Palette

The Command Palette is the main way to access actions in Vela. Its keybinding is one of the first shortcuts to learn: {#kb command_palette::Toggle}.

![The opened Command Palette](https://vela.dev/img/features/command-palette.jpg)

To try it, open the Command Palette and type `new file`. The command list should narrow to {#action workspace::NewFile}. Press Return to create a new buffer.

Any time you see instructions that include commands of the form `vela: ...` or `editor: ...` and so on, it means you need to execute them in the Command Palette.
