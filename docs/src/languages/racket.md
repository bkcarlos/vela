# Racket

Racket support is available through the [Racket extension](https://github.com/vela-extensions/racket).

- Tree-sitter: [vela-industries/tree-sitter-racket](https://github.com/vela-industries/tree-sitter-racket)

The [racket-language-server](https://docs.racket-lang.org/racket-language-server/index.html) is not yet supported in Vela, please see [Issue #15789](https://github.com/vela-industries/vela/issues/15789) for more information.
