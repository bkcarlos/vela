# Yara

`Yara` language support in Vela is provided by the [Yara language extension](https://github.com/egibs/yara.vela). Please report issues to [https://github.com/egibs/yara.vela/issues](https://github.com/egibs/yara.vela/issues).

- Tree-sitter: [egibs/tree-sitter-yara](https://github.com/egibs/tree-sitter-yara)
- Language Server: [avast/yls](https://github.com/avast/yls)
